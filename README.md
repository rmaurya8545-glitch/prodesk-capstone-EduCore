# EduCore: Enterprise Learning Management System

EduCore is a scalable online learning platform (inspired by Udemy and Coursera)
where instructors publish courses with video lessons and students enroll,
learn, and track their progress.

## Designated Track
Fullstack

## Tech Stack
- **Frontend:** React (Vite), Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas with Mongoose
- **Authentication:** JWT (JSON Web Tokens)
- **Media Storage:** Cloudinary (via Multer)
- **Deployment:** Vercel (frontend), Render (backend)

## Core Features (Prioritized)

### P0: Must have
1. User registration and login with two roles: Student and Instructor
2. Course catalog: browse and search all courses
3. Course details page with lesson list
4. Student can enroll in a course
5. Instructor can create a course and upload lessons (video/thumbnail)

### P1: Should have
6. Media player UI to watch a lesson
7. Progress tracking: mark lessons complete, show course progress bar
8. Student dashboard: "My Courses" with progress
9. Instructor dashboard: courses they created

### P2: Nice to have
10. Course reviews and ratings
11. Dark/Light mode

## Out of Scope (to avoid scope creep)
Payments, live classes, AI features, discussion forums, certificates.
